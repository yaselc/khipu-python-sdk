# Security policy

This is a community-maintained SDK. It is not affiliated with, endorsed by, or
maintained by Khipu.

## Reporting a vulnerability in this SDK

Report it privately through GitHub's private vulnerability reporting:
<https://github.com/yaselc/khipu-python-sdk/security/advisories/new>
(the **Report a vulnerability** button on the repository's **Security** tab).

Please do **not** open a public issue, pull request or discussion for a
suspected vulnerability, and never include real Khipu API keys, merchant
secrets or payer data in a report. If a credential has been exposed, revoke it
with Khipu first.

Fixes are released as a new patch version on PyPI; only the latest release is
supported.

## Not in scope

Vulnerabilities in Khipu's own API, applications or infrastructure are outside
this project's control. Report those to Khipu directly.
